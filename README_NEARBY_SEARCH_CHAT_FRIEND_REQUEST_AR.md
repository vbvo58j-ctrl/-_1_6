# فتح محادثة المستخدم القريب وطلب الصداقة

- عند اختيار مستخدم من نتائج البحث القريب، يعاد التحقق من هوية Blousab عبر Bluetooth.
- إذا كان المستخدم صديقاً محفوظاً في `QrFriendStore`، تفتح المحادثة مباشرة.
- إذا لم يكن صديقاً، يرسل التطبيق حزمة `friend_request` عبر اتصال Bluetooth المحلي، ويحفظ الطلب الصادر محلياً، ثم يفتح شاشة المحادثة.
- عند استقبال طلب عبر Bluetooth، يتحقق التطبيق من البروتوكول ومعرّف الجهاز الموثق المرتبط بعنوان الاتصال قبل حفظ الطلب في `FriendRequests`.
- لا تُضاف الصداقة تلقائياً؛ يلزم قبول الطرف الآخر للطلب.

لم يتم تشغيل Flutter analyzer أو بناء APK في هذه البيئة، لذا يلزم التحقق النهائي باستخدام Flutter SDK وتجربة هاتفين فعليين.
